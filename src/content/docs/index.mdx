[Chart.js](https://www.chartjs.org/) **v4+** extension for creating circle packing charts: each value is a circle whose area is proportional to the value, and the circles touch without overlapping in one cluster fitted to the chart area.

![Circle pack example image](/circlepack.png)

## Installation

```bash
npm install chartjs-chart-circlepack
```
